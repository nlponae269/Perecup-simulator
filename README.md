# Объявка — симулятор перекупа

Мобильная «барахолка» в стиле популярных досок объявлений: покупай дёшево, торгуйся в чатах, продавай дороже, не попадись мошенникам.
Цель — вырастить 15 000 ₽ до 1 000 000 ₽.

- Чаты с «людьми» — скриптовые боты с характерами (вежливый, жадный, хам, хитрый, срочно продаёт, мошенник). Никаких внешних API, всё работает офлайн.
- Дефекты, осмотр при встрече, ремонт, продвижение, мошеннические схемы (предоплата, «код из СМС»).
- Прогресс сохраняется в `localStorage`.

## Запуск
Просто открыть `www/index.html` или задеплоить папку `www` как статику.

### Vercel
Импортируйте репозиторий на vercel.com → New Project (настройки подхватятся из `vercel.json`, сборка не нужна). Или:
```
npx vercel --prod
```

### APK
```
sudo apt install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
./build_apk.sh Obyavka.apk
```
Скрипт копирует `www/` в WebView-обёртку (`android/`) и подписывает APK. Готовые сборки — в разделе Releases.
